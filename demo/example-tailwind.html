Demonstration of Select2Icon in Input, Dropdown, and Inline modes.

fas fa-cloud-upload-alt

This demo showcases the Select2Icon icon picker in various modes:

Input Mode: Allows users to type and search for icons in a text input field. The icon list can be loaded from an external JSON file or provided directly as an object.

Dropdown Mode: Presents a button that, when clicked, displays a dropdown menu of icons for selection. The selected icon is reflected on the button itself.

Inline Mode: Displays the icon picker directly within the page layout, allowing users to select icons without additional clicks. This mode can include headers, footers, and custom text.

Each mode is customizable with options such as icon sources, event handlers for selection, and UI elements like headers and footers.

Example code to initialize a basic Select2Icon picker: 

new select2icon({
    target: '#icon-picker-input',
    icons: [
        "fa fa-home","fa fa-search",
        "fa fa-user","fa fa-cog",
        "fa fa-archway"],
    onSelected: (key) => console.log('Selected icon:', key)
  });

You can also use any library of icons, images, or even emojis.
